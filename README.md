## 🏎️ Features

- **Liquid Glass Navigation:** Centered floating glassmorphic header with champagne accents (`#C5A48E`) and responsive mobile drawer.
- **Hero Video Experience:** Seamless supercar ignition loop (`/videos/ferrari-ignition.mp4`) optimized for zero layout shift.
- **UAE Climate Hardening:** 4 technical cards engineered for 50°C+ thermal shock, sandstorm abrasion, and 99.8% UV reflection.
- **Dynamic Commission Schedule:** Vehicle class selector (Sports / Supercar / Hypercar / SUV) with transparent AED pricing.
- **Cleanroom Standards:** ISO Class 7 protocols, Graphtec DAP plotters, and DeFelsko ultrasonic paint depth gauging.
- **Direct WhatsApp Concierge:** Instant WhatsApp booking with pre-filled technical parameters.
